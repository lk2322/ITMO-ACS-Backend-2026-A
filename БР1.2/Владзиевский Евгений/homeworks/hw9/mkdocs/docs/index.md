# Rental Property

Микросервисное приложение для аренды недвижимости: публикация объектов,
поиск с фильтрами, бронирование, оплата и переписка между арендатором и
владельцем.

## Что это за система

| Характеристика | Значение |
|---|---|
| Язык и фреймворк | Go 1.24, Gin |
| Хранилище | PostgreSQL 16, по базе на сервис |
| Асинхронное взаимодействие | Apache Kafka, паттерн Transactional Outbox |
| Оркестрация | Kubernetes (k3s) |
| Точка входа | Ingress Traefik → API Gateway |
| Мониторинг | Prometheus, Loki, Grafana |
| Развёртывание | GitHub Actions → кластер |

## Быстрый старт

```bash
# проверить, что API отвечает
curl http://192.168.1.245/health

# зарегистрироваться и получить токен
curl -X POST http://192.168.1.245/api/v1/auth/register \
     -H 'Content-Type: application/json' \
     -d '{"email":"user@example.com","password":"Passw0rd!",
          "full_name":"Иван Иванов","role":"tenant"}'

# запрос с токеном
curl -H "Authorization: Bearer $TOKEN" \
     http://192.168.1.245/api/v1/properties
```

## Роли пользователей

| Роль | Что может |
|---|---|
| `tenant` | искать объекты, бронировать, оплачивать, писать владельцу |
| `owner` | публиковать и редактировать объекты, отвечать на сообщения |
| `admin` | управлять справочниками и ролями пользователей |

Роль выдаётся при регистрации (`tenant` или `owner`) и хранится в JWT;
`admin` назначается существующим администратором.
