# Развёртывание

История развёртывания приложения по работам курса — каждая следующая
заменяла предыдущую, а не дополняла.

| Работа | Способ | Что появилось |
|---|---|---|
| ЛР3 | Docker Compose локально | образы сервисов, общая сеть |
| ЛР4 | Compose на сервере + nginx | production-конфигурация, обратный прокси, секреты в `.env` |
| ЛР5 | Ansible | настройка сервера описана ролями, идемпотентно |
| ДЗ6 | GitHub Actions | автодеплой Compose-стека по push |
| ЛР7 | Kubernetes (k3s) | манифесты, пробы, PVC, Ingress вместо nginx |
| ДЗ8 | GitHub Actions → кластер | CI с тестами, образы с тегом по SHA, откат |

## Текущая схема

```
 git push → GitHub Actions
                │
                ├─ CI: go vet, сборка, тесты (раннеры GitHub)
                │
                └─ CD: self-hosted runner на сервере
                        сборка образов rental/<сервис>:<SHA>
                        импорт в containerd k3s
                        kubectl apply -k
                        rollout status + smoke-тест
                        откат при неудаче
```

## Состав кластера

```bash
kubectl -n rental get pods
```

| Ресурс | Количество | Тип |
|---|---|---|
| Микросервисы | 6 (шлюз в 2 репликах) | Deployment |
| Базы PostgreSQL | 5 | StatefulSet + PVC |
| Kafka, ZooKeeper | 2 | StatefulSet + PVC |
| Точка входа | 1 | Ingress (Traefik) |

## Ручное развёртывание

Если нужно развернуть без пайплайна:

```bash
# собрать образы и положить их в containerd кластера
/opt/rental-k8s/scripts/build-images.sh /opt/rental-app

# применить манифесты (секреты создаются при первом запуске)
/opt/rental-k8s/scripts/deploy.sh
```

## Конфигурация

| Где | Что лежит |
|---|---|
| ConfigMap `rental-config` | адреса сервисов, порты, параметры загрузки файлов |
| Secret `rental-secrets` | `JWT_SECRET`, `SERVICE_TOKEN`, пароли пяти баз |

Секреты генерируются при первом развёртывании случайными значениями и в
репозиторий не попадают — в git хранится только пример
`secret.example.yaml`.

!!! tip "Добавили сервис, который сам проверяет JWT?"
    Не забудьте передать ему `JWT_SECRET` из секрета — иначе он молча
    возьмёт значение по умолчанию и будет отвергать все токены.
